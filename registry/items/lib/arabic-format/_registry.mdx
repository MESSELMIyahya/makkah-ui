## Usage

Import the helper you need. Every function is a plain function built on `Intl`, so it works in
React components, server code and scripts alike. Formatters are cached per locale and options.

```tsx
import { formatHijriDate, formatPrayerTime, formatSar } from "@/lib/arabic-format";

export function ZakatSummary({ amount, dueDate }: { amount: number; dueDate: Date }) {
  return (
    <p>
      {formatSar(amount)} · {formatHijriDate(dueDate)}
    </p>
  );
}
```

Arabic output uses Arabic-Indic digits. Pass `locale: "en"` for English text with Latin digits.

```ts
formatHijriDate(new Date(2027, 1, 8)); // "١ رمضان ١٤٤٨ هـ"
formatHijriDate(new Date(2027, 1, 8), { locale: "en" }); // "Ramadan 1, 1448 AH"
formatPrayerTime(new Date(2027, 1, 8, 18, 12)); // "٦:١٢ م"
formatSar(2500, { locale: "en" }); // "SAR 2,500.00"
```

## Notes

Hijri dates use the `islamic-umalqura` calendar, the official calendar in Saudi Arabia. Dates are
formatted in the runtime time zone, so build them with local components (for example
`new Date(2027, 1, 8)`) rather than UTC strings. Actual month starts may differ from the calculated
calendar where moon sighting is used.
