## Anatomy

```tsx
<Separator orientation="horizontal" />
```

## Usage

```tsx
import { Separator } from "@/components/ui/separator";
```

```tsx
<Separator className="my-4" />
```

Use a horizontal separator between stacked sections and a vertical one between inline items. A
vertical separator stretches to the height of its flex parent, so give the parent a height.
