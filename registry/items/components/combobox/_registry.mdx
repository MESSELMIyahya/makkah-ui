## Anatomy

```tsx
<Combobox>
  <ComboboxInput />
  <ComboboxContent>
    <ComboboxEmpty />
    <ComboboxList>
      <ComboboxGroup>
        <ComboboxLabel />
        <ComboboxCollection>
          <ComboboxItem />
        </ComboboxCollection>
      </ComboboxGroup>
      <ComboboxSeparator />
    </ComboboxList>
  </ComboboxContent>
</Combobox>
```

For multiple selection, replace `ComboboxInput` with chips anchored to the popup:

```tsx
<Combobox multiple>
  <ComboboxChips>
    <ComboboxValue>
      <ComboboxChip />
      <ComboboxChipsInput />
    </ComboboxValue>
  </ComboboxChips>
  <ComboboxContent>
    <ComboboxList>
      <ComboboxItem />
    </ComboboxList>
  </ComboboxContent>
</Combobox>
```

## Usage

```tsx
import {
  Combobox,
  ComboboxChip,
  ComboboxChips,
  ComboboxChipsInput,
  ComboboxCollection,
  ComboboxContent,
  ComboboxEmpty,
  ComboboxGroup,
  ComboboxInput,
  ComboboxItem,
  ComboboxLabel,
  ComboboxList,
  ComboboxSeparator,
  ComboboxValue,
  useComboboxAnchor,
} from "@/components/ui/combobox";
```

```tsx
const masjids = [
  { value: "haram", label: "Masjid al-Haram" },
  { value: "nabawi", label: "Masjid an-Nabawi" },
  { value: "quba", label: "Masjid Quba" },
];

<Combobox items={masjids}>
  <ComboboxInput placeholder="Choose a masjid" aria-label="Masjid" />
  <ComboboxContent>
    <ComboboxEmpty>No masjid found.</ComboboxEmpty>
    <ComboboxList>
      {(item) => (
        <ComboboxItem key={item.value} value={item}>
          {item.label}
        </ComboboxItem>
      )}
    </ComboboxList>
  </ComboboxContent>
</Combobox>;
```

Pass the options to `items` and render them with a function child of `ComboboxList`. The input
filters the list as the user types. Objects shaped like `{ value, label }` are matched and displayed by
their `label` without extra configuration.

## RTL

Item padding, the check indicator, the chip remove button and the input addons use logical properties,
so the combobox mirrors in Arabic without changes. The popup is portaled to the body and follows the
nearest `DirectionProvider`, so wrap RTL apps with `<DirectionProvider direction="rtl">` from the
`direction` item.
