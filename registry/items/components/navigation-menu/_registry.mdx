## Anatomy

```tsx
<NavigationMenu>
  <NavigationMenuList>
    <NavigationMenuItem>
      <NavigationMenuTrigger />
      <NavigationMenuContent>
        <NavigationMenuLink />
      </NavigationMenuContent>
    </NavigationMenuItem>
    <NavigationMenuItem>
      <NavigationMenuLink className={navigationMenuTriggerStyle()} />
    </NavigationMenuItem>
  </NavigationMenuList>
</NavigationMenu>
```

## Usage

```tsx
import {
  NavigationMenu,
  NavigationMenuContent,
  NavigationMenuItem,
  NavigationMenuLink,
  NavigationMenuList,
  NavigationMenuTrigger,
  navigationMenuTriggerStyle,
} from "@/components/ui/navigation-menu";
```

```tsx
<NavigationMenu>
  <NavigationMenuList>
    <NavigationMenuItem>
      <NavigationMenuTrigger>Journeys</NavigationMenuTrigger>
      <NavigationMenuContent>
        <NavigationMenuLink href="/umrah">Umrah packages</NavigationMenuLink>
      </NavigationMenuContent>
    </NavigationMenuItem>
  </NavigationMenuList>
</NavigationMenu>
```

`NavigationMenu` renders the shared positioner, popup, and viewport for you, so the content of the
open item animates inside one floating panel. Style a top-level link like a trigger with
`navigationMenuTriggerStyle()`.

### NavigationMenuIndicator

Built on Base UI `NavigationMenu.Icon`. A small arrow that can be placed in a trigger.

### navigationMenuTriggerStyle

A `cva` helper that returns the trigger classes, used to style top-level links like triggers.

## RTL

`align="start"` follows the reading direction, so the popup lines up with the start edge of the
trigger in Arabic layouts. Content transitions mirror their horizontal slide in RTL.

The popup is rendered in a portal outside your RTL subtree, so it follows the nearest
`DirectionProvider`. Wrap RTL apps with `<DirectionProvider direction="rtl">` from the
`direction` item so the popup mirrors correctly.
