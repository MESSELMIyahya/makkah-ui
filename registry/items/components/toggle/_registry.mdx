## Anatomy

```tsx
<Toggle>
  <Icon data-icon="inline-start" />
  Label
</Toggle>
```

## Usage

```tsx
import { IconBell } from "@tabler/icons-react";

import { Toggle } from "@/components/ui/toggle";
```

```tsx
<Toggle aria-label="Adhan reminder">
  <IconBell />
</Toggle>
```

The pressed state is exposed as `aria-pressed`, which also drives the pressed background. Give
icon-only toggles an `aria-label`.

### toggleVariants

A `cva` helper that returns the toggle classes for a given `variant` and `size`. It is also used by
`ToggleGroupItem`.

## RTL

Icons marked with `data-icon="inline-start"` or `data-icon="inline-end"` get logical padding
(`ps`/`pe`), so they sit on the correct side in Arabic and English layouts.
