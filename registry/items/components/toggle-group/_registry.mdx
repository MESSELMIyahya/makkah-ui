## Anatomy

```tsx
<ToggleGroup>
  <ToggleGroupItem />
</ToggleGroup>
```

## Usage

```tsx
import { ToggleGroup, ToggleGroupItem } from "@/components/ui/toggle-group";
```

```tsx
<ToggleGroup variant="outline" defaultValue={["standard"]}>
  <ToggleGroupItem value="standard">Standard</ToggleGroupItem>
  <ToggleGroupItem value="hanafi">Hanafi</ToggleGroupItem>
</ToggleGroup>
```

The group value is always an array of item values. By default only one item can be pressed at a
time; add `multiple` to allow several. `variant` and `size` set on the group apply to every item.

## RTL

Joined groups (`spacing={0}`) round the first and last items with `rounded-s` and `rounded-e`, and
remove the shared border with `border-s-0`, so the pill shape stays correct in Arabic layouts. Arrow
key navigation follows the direction from the nearest `DirectionProvider`.
