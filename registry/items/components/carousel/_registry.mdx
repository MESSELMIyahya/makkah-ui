## Anatomy

```tsx
<Carousel>
  <CarouselContent>
    <CarouselItem />
  </CarouselContent>
  <CarouselPrevious />
  <CarouselNext />
</Carousel>
```

## Usage

```tsx
import {
  Carousel,
  CarouselContent,
  CarouselItem,
  CarouselNext,
  CarouselPrevious,
} from "@/components/ui/carousel";
```

```tsx
<Carousel opts={{ direction: "rtl" }}>
  <CarouselContent>
    <CarouselItem>Fajr</CarouselItem>
    <CarouselItem>Dhuhr</CarouselItem>
    <CarouselItem>Asr</CarouselItem>
  </CarouselContent>
  <CarouselPrevious />
  <CarouselNext />
</Carousel>
```

`opts` is passed to [Embla](https://www.embla-carousel.com/api/options/) and `plugins` accepts Embla
plugins such as autoplay. Set the width of each slide with a `basis-*` class on `CarouselItem`.

## RTL

Embla does not read the `dir` attribute on its own. Pass `opts={{ direction: "rtl" }}` in Arabic
layouts so slides scroll and snap from the right edge. The examples read the direction from Base UI's
`DirectionProvider`:

```tsx
import { useDirection } from "@base-ui/react/direction-provider";

const direction = useDirection();

<Carousel opts={{ direction }}>{/* ... */}</Carousel>;
```

The previous and next buttons are positioned with `start`/`end` and their chevrons rotate in RTL, so
"previous" always sits on the start side. The built-in Arrow Left and Arrow Right key handlers are not
direction-aware: Arrow Left always moves to the previous slide.
