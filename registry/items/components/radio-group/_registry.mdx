## Anatomy

```tsx
<RadioGroup>
  <RadioGroupItem value="option" id="option" />
  <Label htmlFor="option">Label</Label>
</RadioGroup>
```

## Usage

```tsx
import { Label } from "@/components/ui/label";
import { RadioGroup, RadioGroupItem } from "@/components/ui/radio-group";
```

```tsx
<RadioGroup defaultValue="umm-al-qura">
  <div className="flex items-center gap-3">
    <RadioGroupItem value="umm-al-qura" id="umm-al-qura" />
    <Label htmlFor="umm-al-qura">Umm al-Qura, Makkah</Label>
  </div>
  <div className="flex items-center gap-3">
    <RadioGroupItem value="mwl" id="mwl" />
    <Label htmlFor="mwl">Muslim World League</Label>
  </div>
</RadioGroup>
```

Give the group an accessible name with `aria-label`, or wrap it in a `FieldSet` with a
`FieldLegend`. Arrow keys move between items.

## RTL

The indicator dot is centered with logical positioning and a direction-aware translate, so it stays
centered in both directions. Arrow key navigation follows the text direction.
