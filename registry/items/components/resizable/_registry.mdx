## Anatomy

```tsx
<ResizablePanelGroup>
  <ResizablePanel />
  <ResizableHandle />
  <ResizablePanel />
</ResizablePanelGroup>
```

## Usage

```tsx
import { ResizableHandle, ResizablePanel, ResizablePanelGroup } from "@/components/ui/resizable";
```

```tsx
<ResizablePanelGroup orientation="horizontal">
  <ResizablePanel defaultSize="40%">Masjids</ResizablePanel>
  <ResizableHandle />
  <ResizablePanel defaultSize="60%">Prayer times</ResizablePanel>
</ResizablePanelGroup>
```

Built on [react-resizable-panels](https://react-resizable-panels.vercel.app) v4. Sizes given as
numbers are pixels; strings without a unit, or with `%`, are percentages of the group.

## RTL

Horizontal groups follow the document direction, so the first panel sits on the right in Arabic
layouts and the handle's hit area is centered with `start-1/2`. react-resizable-panels calculates
pointer and arrow key movement in physical screen coordinates, so in RTL a horizontal drag and the
Arrow Left and Arrow Right keys move the separator in the opposite direction to the pointer. Vertical
groups are not affected.
