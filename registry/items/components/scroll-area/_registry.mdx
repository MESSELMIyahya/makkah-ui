## Anatomy

```tsx
<ScrollArea>
  {children}
  <ScrollBar orientation="horizontal" />
</ScrollArea>
```

`ScrollArea` renders the viewport, a vertical `ScrollBar`, and the corner for you.

## Usage

```tsx
import { ScrollArea, ScrollBar } from "@/components/ui/scroll-area";
```

```tsx
<ScrollArea className="h-64 rounded-xl border">
  <div className="p-4">Lecture schedule…</div>
</ScrollArea>
```

Give the scroll area a fixed height (or width for horizontal content) so it can overflow.

## RTL

The vertical scrollbar uses `border-s` and is positioned by Base UI from the reading direction, so it
appears on the left in Arabic and on the right in English.
