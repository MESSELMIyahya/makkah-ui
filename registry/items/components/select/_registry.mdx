## Anatomy

```tsx
<Select>
  <SelectTrigger>
    <SelectValue />
  </SelectTrigger>
  <SelectContent>
    <SelectGroup>
      <SelectLabel />
      <SelectItem />
    </SelectGroup>
    <SelectSeparator />
  </SelectContent>
</Select>
```

## Usage

```tsx
import {
  Select,
  SelectContent,
  SelectGroup,
  SelectItem,
  SelectLabel,
  SelectSeparator,
  SelectTrigger,
  SelectValue,
} from "@/components/ui/select";
```

```tsx
const cities = [
  { label: "Makkah", value: "makkah" },
  { label: "Madinah", value: "madinah" },
];

<Select items={cities}>
  <SelectTrigger aria-label="City">
    <SelectValue placeholder="Select a city" />
  </SelectTrigger>
  <SelectContent>
    {cities.map((city) => (
      <SelectItem key={city.value} value={city.value}>
        {city.label}
      </SelectItem>
    ))}
  </SelectContent>
</Select>;
```

Pass `items` to `Select` so `SelectValue` can show the label of the selected value before the
popup has opened.

## RTL

The trigger icon, item padding and check indicator use logical properties, and item text aligns to
the inline start, so the select mirrors in Arabic without changes. The popup is portaled to the body
and follows the nearest `DirectionProvider`, so wrap RTL apps with `<DirectionProvider direction="rtl">`
from the `direction` item.

The item list is rendered in a portal outside your RTL subtree, so it follows the nearest
`DirectionProvider`. Wrap RTL apps with `<DirectionProvider direction="rtl">` from the
`direction` item so the item list mirrors correctly.
