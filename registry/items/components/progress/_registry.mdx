## Anatomy

```tsx
<Progress>
  <ProgressLabel />
  <ProgressValue />
</Progress>
```

`Progress` renders `ProgressTrack` and `ProgressIndicator` for you after its children.

## Usage

```tsx
import { Progress, ProgressLabel, ProgressValue } from "@/components/ui/progress";
```

```tsx
<Progress value={12} max={30}>
  <ProgressLabel>Ramadan fasts</ProgressLabel>
  <ProgressValue />
</Progress>
```

Give every progress bar a name, either with `ProgressLabel` or an `aria-label`.

## RTL

The indicator fills from the inline start, so it grows from right to left in Arabic. The value sits
at the inline end with `ms-auto`.
