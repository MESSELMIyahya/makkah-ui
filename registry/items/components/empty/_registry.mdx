## Anatomy

```tsx
<Empty>
  <EmptyHeader>
    <EmptyMedia />
    <EmptyTitle />
    <EmptyDescription />
  </EmptyHeader>
  <EmptyContent />
</Empty>
```

## Usage

```tsx
import { IconBellRinging } from "@tabler/icons-react";

import { Button } from "@/components/ui/button";
import {
  Empty,
  EmptyContent,
  EmptyDescription,
  EmptyHeader,
  EmptyMedia,
  EmptyTitle,
} from "@/components/ui/empty";
```

```tsx
<Empty>
  <EmptyHeader>
    <EmptyMedia variant="icon">
      <IconBellRinging />
    </EmptyMedia>
    <EmptyTitle>No prayer reminders yet</EmptyTitle>
    <EmptyDescription>Add a reminder and we will notify you on time.</EmptyDescription>
  </EmptyHeader>
  <EmptyContent>
    <Button>Add reminder</Button>
  </EmptyContent>
</Empty>
```

Use an empty state wherever a list, table or search can have no data. `EmptyContent` holds the actions
that help the user fill it.

### EmptyHeader, EmptyTitle, EmptyDescription and EmptyContent

`EmptyHeader` stacks the media, title and description. `EmptyTitle` and `EmptyDescription` style the text,
and links inside the description are underlined. `EmptyContent` holds actions such as buttons or a search
input.

## RTL

Every part is centered and the text uses `text-balance`, so the empty state looks the same in Arabic and
English. Mirror directional icons inside actions with `rtl:-scale-x-100`.
