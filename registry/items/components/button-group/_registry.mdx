## Anatomy

```tsx
<ButtonGroup>
  <Button />
  <ButtonGroupSeparator />
  <ButtonGroupText />
  <Button />
</ButtonGroup>
```

## Usage

```tsx
import { Button } from "@/components/ui/button";
import { ButtonGroup, ButtonGroupSeparator, ButtonGroupText } from "@/components/ui/button-group";
```

```tsx
<ButtonGroup aria-label="Lecture actions">
  <Button variant="outline">Add to calendar</Button>
  <Button variant="outline">Share</Button>
</ButtonGroup>
```

The group removes the inner corners and the shared border of its direct children, so any element
with a `data-slot` (buttons, inputs, select triggers) joins into one control. Give the group an
`aria-label` that describes the set.

## RTL

Corner rounding and border removal use logical utilities (`rounded-s`, `rounded-e`, `border-s`), so the
first child is rounded on the start side in both Arabic and English layouts. Mirror directional icons
with `rtl:-scale-x-100`, as in the nested example.
