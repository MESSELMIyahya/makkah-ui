## Anatomy

```tsx
<FieldSet>
  <FieldLegend>Legend</FieldLegend>
  <FieldDescription>Description</FieldDescription>
  <FieldGroup>
    <Field>
      <FieldLabel htmlFor="control-id">Label</FieldLabel>
      <Input id="control-id" />
      <FieldDescription>Helper text</FieldDescription>
      <FieldError>Error message</FieldError>
    </Field>
    <FieldSeparator>Or</FieldSeparator>
    <Field orientation="horizontal">
      <Checkbox id="option-id" />
      <FieldContent>
        <FieldLabel htmlFor="option-id">Label</FieldLabel>
        <FieldDescription>Description</FieldDescription>
      </FieldContent>
    </Field>
  </FieldGroup>
</FieldSet>
```

## Usage

```tsx
import { Checkbox } from "@/components/ui/checkbox";
import {
  Field,
  FieldContent,
  FieldDescription,
  FieldError,
  FieldGroup,
  FieldLabel,
  FieldLegend,
  FieldSeparator,
  FieldSet,
  FieldTitle,
} from "@/components/ui/field";
import { Input } from "@/components/ui/input";
```

```tsx
<Field>
  <FieldLabel htmlFor="mobile-number">Mobile number</FieldLabel>
  <Input id="mobile-number" type="tel" />
  <FieldDescription>We send prayer time reminders by SMS.</FieldDescription>
</Field>
```

`Field` handles layout only; it works with any control, including `Input`, `Textarea`, `Select`,
`Checkbox`, `RadioGroup` and `Switch`, and with any form library.

### FieldGroup, FieldContent, FieldTitle and FieldDescription

`FieldGroup` stacks fields and acts as the container query for responsive fields. `FieldContent`
groups a label and description next to a control. `FieldTitle` is a non-label title for choice
cards. `FieldDescription` renders helper text in a `<p>`.

## Accessibility

Link labels with `htmlFor`, and link descriptions or errors to the control with `aria-describedby`
when they are not announced otherwise. `FieldError` uses `role="alert"`, so new errors are announced
as they appear.
