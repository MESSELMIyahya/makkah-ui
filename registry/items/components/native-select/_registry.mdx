## Anatomy

```tsx
<NativeSelect>
  <NativeSelectOptGroup>
    <NativeSelectOption />
  </NativeSelectOptGroup>
</NativeSelect>
```

## Usage

```tsx
import {
  NativeSelect,
  NativeSelectOptGroup,
  NativeSelectOption,
} from "@/components/ui/native-select";
```

```tsx
<NativeSelect aria-label="City" defaultValue="makkah">
  <NativeSelectOption value="makkah">Makkah</NativeSelectOption>
  <NativeSelectOption value="madinah">Madinah</NativeSelectOption>
</NativeSelect>
```

`NativeSelect` renders a real `<select>`, so it uses the platform picker on mobile and works in forms
without JavaScript. Use the `Select` component when you need custom item content or styling of the popup.

## RTL

The selector icon and the select padding use logical properties (`end-3.5`, `ps-3`, `pe-8`), so the icon
sits on the inline end in Arabic. The options list is drawn by the browser and follows the `dir` of the
page.
