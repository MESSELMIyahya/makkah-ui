## Anatomy

```tsx
<Collapsible>
  <CollapsibleTrigger />
  <CollapsibleContent />
</Collapsible>
```

## Usage

```tsx
import {
  Collapsible,
  CollapsibleContent,
  CollapsibleTrigger,
} from "@/components/ui/collapsible";
```

```tsx
<Collapsible>
  <CollapsibleTrigger>Package includes</CollapsibleTrigger>
  <CollapsibleContent>Flights, hotel, and visa processing.</CollapsibleContent>
</Collapsible>
```

The parts are unstyled. Use the `render` prop on `CollapsibleTrigger` to render a `Button`, and the
`data-panel-open` attribute on the trigger to style the open state.
