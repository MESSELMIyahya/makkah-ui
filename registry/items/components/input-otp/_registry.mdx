## Anatomy

```tsx
<InputOTP maxLength={6}>
  <InputOTPGroup>
    <InputOTPSlot index={0} />
    <InputOTPSlot index={1} />
    <InputOTPSlot index={2} />
  </InputOTPGroup>
  <InputOTPSeparator />
  <InputOTPGroup>
    <InputOTPSlot index={3} />
    <InputOTPSlot index={4} />
    <InputOTPSlot index={5} />
  </InputOTPGroup>
</InputOTP>
```

## Usage

```tsx
import { InputOTP, InputOTPGroup, InputOTPSeparator, InputOTPSlot } from "@/components/ui/input-otp";
```

```tsx
<InputOTP maxLength={4}>
  <InputOTPGroup>
    <InputOTPSlot index={0} />
    <InputOTPSlot index={1} />
    <InputOTPSlot index={2} />
    <InputOTPSlot index={3} />
  </InputOTPGroup>
</InputOTP>
```

Render one `InputOTPSlot` per character, with indexes from `0` to `maxLength - 1`. A single hidden
input handles typing, pasting and SMS autofill.

### InputOTPGroup and InputOTPSeparator

`InputOTPGroup` joins adjacent slots into one rounded block. `InputOTPSeparator` renders a dash
with `role="separator"` between groups.

## RTL

Slot borders and rounded corners use logical properties. Slots follow the document direction, so
in Arabic the first character fills the rightmost slot.
