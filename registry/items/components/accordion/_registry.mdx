## Anatomy

```tsx
<Accordion>
  <AccordionItem>
    <AccordionTrigger />
    <AccordionContent />
  </AccordionItem>
</Accordion>
```

## Usage

```tsx
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@/components/ui/accordion";
```

```tsx
<Accordion>
  <AccordionItem value="ihram">
    <AccordionTrigger>Where do I enter ihram?</AccordionTrigger>
    <AccordionContent>At the miqat on your route.</AccordionContent>
  </AccordionItem>
</Accordion>
```

Give each item a unique `value`. The open state is an array of those values, even when only one
item can be open.

## RTL

Triggers align with `text-start` and the chevron is pushed to the inline end with `ms-auto`. Up and
down chevrons need no mirroring.
