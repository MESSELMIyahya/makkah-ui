## Anatomy

```tsx
<Switch id="setting" />
<Label htmlFor="setting">Label</Label>
```

## Usage

```tsx
import { Label } from "@/components/ui/label";
import { Switch } from "@/components/ui/switch";
```

```tsx
<Switch id="adhan-alerts" defaultChecked />
<Label htmlFor="adhan-alerts">Adhan notifications</Label>
```

Use a switch for settings that apply immediately, such as notifications. For choices that are
submitted with a form, prefer a checkbox.

## RTL

The thumb moves toward the inline end when checked: to the left in Arabic and to the right in
English. No extra classes are needed.
