## Anatomy

```tsx
<AvatarGroup>
  <Avatar>
    <AvatarImage />
    <AvatarFallback />
    <AvatarBadge />
  </Avatar>
  <AvatarGroupCount />
</AvatarGroup>
```

## Usage

```tsx
import {
  Avatar,
  AvatarBadge,
  AvatarFallback,
  AvatarGroup,
  AvatarGroupCount,
  AvatarImage,
} from "@/components/ui/avatar";
```

```tsx
<Avatar>
  <AvatarImage src="/teachers/abdullah.jpg" alt="Abdullah Hassan" />
  <AvatarFallback>AH</AvatarFallback>
</Avatar>
```

`AvatarFallback` shows while the image loads or when it fails, so always provide initials. Arabic
initials work the same way, for example `عح`.

## RTL

`AvatarBadge` is placed with `end-0`, so it sits on the bottom left in Arabic and the bottom right in
English.
