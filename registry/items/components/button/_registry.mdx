## Anatomy

```tsx
<Button>
  <Icon data-icon="inline-start" />
  Label
</Button>
```

## Usage

```tsx
import { Button } from "@/components/ui/button";
```

```tsx
<Button variant="outline">Book Umrah</Button>
```

Icons placed inside the button get `data-icon="inline-start"` or `data-icon="inline-end"`. The
padding uses logical properties (`ps`/`pe`), so the icon sits on the correct side in both RTL and
LTR layouts without extra classes.

### buttonVariants

A `cva` helper that returns the button classes. Use it to style other elements like buttons.

```tsx
import { buttonVariants } from "@/components/ui/button";

<a className={buttonVariants({ variant: "outline", size: "sm" })} href="/prayer-times">
  Prayer times
</a>;
```

## RTL

Direction comes from the nearest `dir` attribute. Icons with directional meaning, such as arrows,
should be mirrored in RTL with `rtl:-scale-x-100`.
