## Anatomy

```tsx
<Command>
  <CommandInput />
  <CommandList>
    <CommandEmpty />
    <CommandGroup>
      <CommandItem>
        <CommandShortcut />
      </CommandItem>
    </CommandGroup>
    <CommandSeparator />
  </CommandList>
</Command>
```

## Usage

```tsx
import {
  Command,
  CommandEmpty,
  CommandGroup,
  CommandInput,
  CommandItem,
  CommandList,
  CommandSeparator,
  CommandShortcut,
} from "@/components/ui/command";
```

```tsx
<Command>
  <CommandInput placeholder="Search masjids or cities..." />
  <CommandList>
    <CommandEmpty>No results found.</CommandEmpty>
    <CommandGroup heading="Masjids">
      <CommandItem>Masjid al-Haram</CommandItem>
      <CommandItem>Quba Mosque</CommandItem>
    </CommandGroup>
  </CommandList>
</Command>
```

Built on [cmdk](https://github.com/pacocoursey/cmdk). Items are filtered and ranked as the user
types, and the arrow keys move the selection. Arabic text is matched as typed.

## RTL

Icons, shortcuts and the check indicator use logical spacing. Add transliterated `keywords` to
Arabic items so that users can find them with either script.

The command dialog is rendered in a portal outside your RTL subtree, so it follows the nearest
`DirectionProvider`. Wrap RTL apps with `<DirectionProvider direction="rtl">` from the
`direction` item so the command dialog mirrors correctly.
