## Anatomy

```tsx
<Label htmlFor="control-id">Label text</Label>
```

## Usage

```tsx
import { Input } from "@/components/ui/input";
import { Label } from "@/components/ui/label";
```

```tsx
<Label htmlFor="pilgrim-name">Full name</Label>
<Input id="pilgrim-name" />
```

Point `htmlFor` at the `id` of the control so clicking the label focuses or toggles it and screen
readers announce the label with the control.

## Accessibility

Every form control needs an accessible name. Prefer a visible `Label` linked with `htmlFor`; use
`aria-label` only when there is no room for visible text.
