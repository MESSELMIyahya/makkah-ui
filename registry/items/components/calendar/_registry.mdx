## Anatomy

```tsx
<Calendar mode="single" selected={date} onSelect={setDate} />
```

## Usage

```tsx
import * as React from "react";

import { Calendar } from "@/components/ui/calendar";
```

```tsx
const [date, setDate] = React.useState<Date | undefined>(new Date());

<Calendar mode="single" selected={date} onSelect={setDate} className="rounded-3xl border" />;
```

`Calendar` wraps [React DayPicker](https://daypicker.dev) and accepts all of its props. Localize it
with a locale from `react-day-picker/locale`, such as `arSA`, and pass `numerals="arab"` for
Arabic-Indic digits.

## RTL

The calendar inherits the direction from the nearest `dir` attribute, so weekdays run from right to
left in Arabic layouts. The previous and next chevrons are mirrored with CSS, so do not also pass
`dir="rtl"` to `Calendar`: DayPicker would swap the chevrons a second time.
