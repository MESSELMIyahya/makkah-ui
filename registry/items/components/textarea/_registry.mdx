## Anatomy

```tsx
<Textarea />
```

## Usage

```tsx
import { Textarea } from "@/components/ui/textarea";
```

```tsx
<Textarea placeholder="Suggest a topic for the Friday halaqa" />
```

The textarea grows with its content through `field-sizing: content`, starting from a minimum height.
Set a `max-h-*` class to cap it.
