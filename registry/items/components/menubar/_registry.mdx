## Anatomy

```tsx
<Menubar>
  <MenubarMenu>
    <MenubarTrigger />
    <MenubarContent>
      <MenubarGroup>
        <MenubarLabel />
        <MenubarItem>
          <MenubarShortcut />
        </MenubarItem>
      </MenubarGroup>
      <MenubarSeparator />
      <MenubarCheckboxItem />
      <MenubarRadioGroup>
        <MenubarRadioItem />
      </MenubarRadioGroup>
      <MenubarSub>
        <MenubarSubTrigger />
        <MenubarSubContent />
      </MenubarSub>
    </MenubarContent>
  </MenubarMenu>
</Menubar>
```

## Usage

```tsx
import {
  Menubar,
  MenubarCheckboxItem,
  MenubarContent,
  MenubarGroup,
  MenubarItem,
  MenubarLabel,
  MenubarMenu,
  MenubarRadioGroup,
  MenubarRadioItem,
  MenubarSeparator,
  MenubarShortcut,
  MenubarSub,
  MenubarSubContent,
  MenubarSubTrigger,
  MenubarTrigger,
} from "@/components/ui/menubar";
```

```tsx
<Menubar>
  <MenubarMenu>
    <MenubarTrigger>Schedule</MenubarTrigger>
    <MenubarContent>
      <MenubarItem>New lesson</MenubarItem>
      <MenubarItem>Print Ramadan schedule</MenubarItem>
    </MenubarContent>
  </MenubarMenu>
</Menubar>
```

Each `MenubarMenu` is a dropdown menu. Once one menu is open, hovering or pressing the arrow keys
moves between the menus in the bar.

## RTL

The bar follows the reading direction, so the first menu sits on the right in Arabic, and arrow key
navigation is mirrored by Base UI.

The menu is rendered in a portal outside your RTL subtree, so it follows the nearest
`DirectionProvider`. Wrap RTL apps with `<DirectionProvider direction="rtl">` from the
`direction` item so the menu mirrors correctly.
