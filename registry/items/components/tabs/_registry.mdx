## Anatomy

```tsx
<Tabs>
  <TabsList>
    <TabsTrigger />
  </TabsList>
  <TabsContent />
</Tabs>
```

## Usage

```tsx
import { Tabs, TabsContent, TabsList, TabsTrigger } from "@/components/ui/tabs";
```

```tsx
<Tabs defaultValue="today">
  <TabsList>
    <TabsTrigger value="today">Today</TabsTrigger>
    <TabsTrigger value="tomorrow">Tomorrow</TabsTrigger>
  </TabsList>
  <TabsContent value="today">Today's prayer times.</TabsContent>
  <TabsContent value="tomorrow">Tomorrow's prayer times.</TabsContent>
</Tabs>
```

Each `TabsTrigger` is linked to the `TabsContent` with the same `value`. Set `defaultValue` for an
uncontrolled group, or `value` with `onValueChange` to control the active tab.

## RTL

Base UI reads the direction from the nearest `DirectionProvider`, so the Arrow Left and Arrow Right
keys follow the visual order in RTL. The vertical line indicator uses `end` positioning and the icon
padding uses `ps`/`pe`, so no extra classes are needed.
