## Anatomy

```tsx
<Drawer>
  <DrawerTrigger />
  <DrawerContent>
    <DrawerHeader>
      <DrawerTitle />
      <DrawerDescription />
    </DrawerHeader>
    <DrawerFooter>
      <DrawerClose />
    </DrawerFooter>
  </DrawerContent>
</Drawer>
```

## Usage

```tsx
import { Button } from "@/components/ui/button";
import {
  Drawer,
  DrawerClose,
  DrawerContent,
  DrawerDescription,
  DrawerFooter,
  DrawerHeader,
  DrawerTitle,
  DrawerTrigger,
} from "@/components/ui/drawer";
```

```tsx
<Drawer>
  <DrawerTrigger render={<Button variant="outline" />}>Reminder before adhan</DrawerTrigger>
  <DrawerContent>
    <DrawerHeader>
      <DrawerTitle>Reminder before Fajr</DrawerTitle>
      <DrawerDescription>Choose how many minutes before adhan.</DrawerDescription>
    </DrawerHeader>
    <DrawerFooter>
      <DrawerClose render={<Button />}>Save</DrawerClose>
    </DrawerFooter>
  </DrawerContent>
</Drawer>
```

Drawers suit mobile layouts: they slide up from the bottom by default and close when the user swipes
them back toward the edge.

## RTL

`swipeDirection` follows the physical swipe gesture. Horizontal drawers are positioned with logical
`start`/`end` insets, so check `left` and `right` drawers in both directions when you use them.

The drawer is rendered in a portal outside your RTL subtree, so it follows the nearest
`DirectionProvider`. Wrap RTL apps with `<DirectionProvider direction="rtl">` from the
`direction` item so the drawer mirrors correctly.
