## Anatomy

```tsx
<Card>
  <CardHeader>
    <CardTitle />
    <CardDescription />
    <CardAction />
  </CardHeader>
  <CardContent />
  <CardFooter />
</Card>
```

## Usage

```tsx
import {
  Card,
  CardAction,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardTitle,
} from "@/components/ui/card";
```

```tsx
<Card>
  <CardHeader>
    <CardTitle>Masjid Quba</CardTitle>
    <CardDescription>Quba, Madinah</CardDescription>
  </CardHeader>
  <CardContent>Next prayer: Asr at 3:28 PM</CardContent>
</Card>
```

Every part is a plain `div` with a `data-slot` attribute. Spacing is driven by the `--card-spacing`
variable, so the `size` prop adjusts all parts at once.

Grid wrapper for the title, description, and action. Switches to two columns when a `CardAction` is present.

## RTL

The header grid places `CardAction` with `justify-self-end`, so it sits on the left in Arabic and on
the right in English without extra classes.
