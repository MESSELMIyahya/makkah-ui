## Anatomy

```tsx
<Badge>
  <Icon data-icon="inline-start" />
  Label
</Badge>
```

## Usage

```tsx
import { Badge } from "@/components/ui/badge";
```

```tsx
<Badge variant="secondary">Zakat paid</Badge>
```

Badges render a `span` by default. Use the `render` prop to turn one into a link while keeping its
styles.

## API Reference

### Badge

Built with the Base UI `useRender` hook, so it accepts a `render` prop and every native `span` attribute.

<PropsTable
  rows={[
    {
      prop: "variant",

### badgeVariants

A `cva` helper that returns the badge classes for use on other elements.

```tsx
import { badgeVariants } from "@/components/ui/badge";

<span className={badgeVariants({ variant: "outline" })}>Ramadan 1448</span>;
```

## RTL

Icon padding uses logical properties (`ps`/`pe`). Mirror directional icons such as arrows with
`rtl:-scale-x-100`, as in the With Icon example.
