## Anatomy

```tsx
<HoverCard>
  <HoverCardTrigger />
  <HoverCardContent />
</HoverCard>
```

## Usage

```tsx
import { HoverCard, HoverCardContent, HoverCardTrigger } from "@/components/ui/hover-card";
```

```tsx
<HoverCard>
  <HoverCardTrigger href="/masjids/an-nabawi">Masjid an-Nabawi</HoverCardTrigger>
  <HoverCardContent>The second of the two holy masjids, in Madinah.</HoverCardContent>
</HoverCard>
```

`HoverCardTrigger` renders a link by default. The card opens on hover or keyboard focus and is meant
for supplementary content only, so keep the essential information reachable through the link.

## Accessibility

Touch and screen reader users may never see the card. Do not put actions or information inside it
that are not also available on the linked page.

## RTL

The card is rendered in a portal outside your RTL subtree, so it follows the nearest
`DirectionProvider`. Wrap RTL apps with `<DirectionProvider direction="rtl">` from the
`direction` item so the card mirrors correctly.
