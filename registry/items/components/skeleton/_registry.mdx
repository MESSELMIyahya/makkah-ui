## Anatomy

```tsx
<Skeleton />
```

## Usage

```tsx
import { Skeleton } from "@/components/ui/skeleton";
```

```tsx
<Skeleton className="h-4 w-48" />
```

Size and shape come from `className`. Wrap a group of skeletons in an element with `role="status"`
and an `aria-label` so screen readers announce what is loading.
