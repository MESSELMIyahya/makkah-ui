## Anatomy

```tsx
<Dialog>
  <DialogTrigger />
  <DialogContent>
    <DialogHeader>
      <DialogTitle />
      <DialogDescription />
    </DialogHeader>
    <DialogFooter>
      <DialogClose />
    </DialogFooter>
  </DialogContent>
</Dialog>
```

## Usage

```tsx
import { Button } from "@/components/ui/button";
import {
  Dialog,
  DialogClose,
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
} from "@/components/ui/dialog";
```

```tsx
<Dialog>
  <DialogTrigger render={<Button variant="outline" />}>Booking details</DialogTrigger>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>Umrah trip booking</DialogTitle>
      <DialogDescription>Review your trip before confirming.</DialogDescription>
    </DialogHeader>
    <DialogFooter>
      <DialogClose render={<Button variant="outline" />}>Cancel</DialogClose>
      <Button>Confirm booking</Button>
    </DialogFooter>
  </DialogContent>
</Dialog>
```

Use the `render` prop on `DialogTrigger` and `DialogClose` to render them as a `Button`. Focus is
trapped inside the dialog while it is open and returns to the trigger when it closes.

## RTL

The popup is centered with `start-1/2` and a mirrored translate, and the close button sits at
`end-4`, so it appears in the top-left corner in Arabic and the top-right corner in English.

The dialog is rendered in a portal outside your RTL subtree, so it follows the nearest
`DirectionProvider`. Wrap RTL apps with `<DirectionProvider direction="rtl">` from the
`direction` item so the dialog mirrors correctly.
