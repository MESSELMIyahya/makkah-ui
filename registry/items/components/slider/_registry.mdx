## Anatomy

```tsx
<Slider defaultValue={[50]} min={0} max={100} step={1} />
```

## Usage

```tsx
import { Slider } from "@/components/ui/slider";
```

```tsx
<Slider aria-label="Sadaqah amount" defaultValue={[250]} min={10} max={1000} step={10} />
```

Always pass `value` or `defaultValue` as an array: the number of entries sets the number of thumbs.
Without either, the slider renders two thumbs at `min` and `max`.

## RTL

Horizontal sliders read the nearest `dir` and fill from the inline start: from the right in
Arabic and from the left in English.
