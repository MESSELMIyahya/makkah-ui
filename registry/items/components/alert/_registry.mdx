## Anatomy

```tsx
<Alert>
  <Icon />
  <AlertTitle />
  <AlertDescription />
  <AlertAction />
</Alert>
```

## Usage

```tsx
import { IconBell } from "@tabler/icons-react";

import { Alert, AlertAction, AlertDescription, AlertTitle } from "@/components/ui/alert";
```

```tsx
<Alert>
  <IconBell />
  <AlertTitle>Isha prayer in 15 minutes</AlertTitle>
  <AlertDescription>The adhan is at 8:05 PM.</AlertDescription>
</Alert>
```

Place an icon as the first child and the alert switches to a two-column grid with the icon beside
the title and description.

## RTL

Text aligns with `text-start` and `AlertAction` is placed with `end-3`, so both follow the reading
direction. The alert announces itself to screen readers through `role="alert"`; use it for timely
messages, not static content.
