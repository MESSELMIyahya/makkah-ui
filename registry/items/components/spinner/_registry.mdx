## Anatomy

```tsx
<Spinner />
```

## Usage

```tsx
import { Spinner } from "@/components/ui/spinner";
```

```tsx
<Spinner aria-label="جارٍ التحميل" />
```

The spinner renders with `role="status"` and an English `aria-label` of "Loading". Pass a translated
`aria-label` in Arabic interfaces.
