## Anatomy

```tsx
<AspectRatio ratio={16 / 9}>{children}</AspectRatio>
```

## Usage

```tsx
import { AspectRatio } from "@/components/ui/aspect-ratio";
```

```tsx
<AspectRatio ratio={16 / 9} className="rounded-xl bg-muted">
  <img src="/masjid-quba.jpg" alt="Masjid Quba" className="size-full object-cover" />
</AspectRatio>
```

The component sets the CSS `aspect-ratio` through a `--ratio` variable. Its width comes from the
parent, and the height follows.
