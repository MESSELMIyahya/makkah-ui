## Anatomy

```tsx
<TooltipProvider>
  <Tooltip>
    <TooltipTrigger />
    <TooltipContent />
  </Tooltip>
</TooltipProvider>
```

## Usage

```tsx
import { IconCompass } from "@tabler/icons-react";

import { Button } from "@/components/ui/button";
import { Tooltip, TooltipContent, TooltipProvider, TooltipTrigger } from "@/components/ui/tooltip";
```

```tsx
<Tooltip>
  <TooltipTrigger render={<Button variant="outline" size="icon" aria-label="Qibla direction" />}>
    <IconCompass />
  </TooltipTrigger>
  <TooltipContent>Qibla direction</TooltipContent>
</Tooltip>
```

Wrap your app, or a group of tooltips, in `TooltipProvider` so that moving between triggers opens the
next tooltip instantly. Tooltips are for short, non-essential hints; icon buttons still need an
`aria-label`.

## RTL

`inline-start` and `inline-end` resolve against the nearest direction, and the arrow offset is
mirrored with `rtl:` variants, so the arrow always points at the trigger.

The tooltip is rendered in a portal outside your RTL subtree, so it follows the nearest
`DirectionProvider`. Wrap RTL apps with `<DirectionProvider direction="rtl">` from the
`direction` item so the tooltip mirrors correctly.
