## Anatomy

```tsx
<Sheet>
  <SheetTrigger />
  <SheetContent>
    <SheetHeader>
      <SheetTitle />
      <SheetDescription />
    </SheetHeader>
    <SheetFooter>
      <SheetClose />
    </SheetFooter>
  </SheetContent>
</Sheet>
```

## Usage

```tsx
import { Button } from "@/components/ui/button";
import {
  Sheet,
  SheetClose,
  SheetContent,
  SheetDescription,
  SheetFooter,
  SheetHeader,
  SheetTitle,
  SheetTrigger,
} from "@/components/ui/sheet";
```

```tsx
<Sheet>
  <SheetTrigger render={<Button variant="outline" />}>Masjid details</SheetTrigger>
  <SheetContent>
    <SheetHeader>
      <SheetTitle>Quba Mosque</SheetTitle>
      <SheetDescription>Quba district, Madinah</SheetDescription>
    </SheetHeader>
  </SheetContent>
</Sheet>
```

A sheet is a dialog that slides in from an edge of the screen. It shares the focus trapping and
dismissal behavior of `Dialog`.

## RTL

`side` uses physical edges, so `side="right"` stays on the right in both directions. The borders
and close button use logical properties. For a sheet that opens from the inline-end edge in both
languages, pick the side from the current direction: `left` in Arabic and `right` in English.

The sheet is rendered in a portal outside your RTL subtree, so it follows the nearest
`DirectionProvider`. Wrap RTL apps with `<DirectionProvider direction="rtl">` from the
`direction` item so the sheet mirrors correctly.
