## Anatomy

```tsx
<Popover>
  <PopoverTrigger />
  <PopoverContent>
    <PopoverHeader>
      <PopoverTitle />
      <PopoverDescription />
    </PopoverHeader>
  </PopoverContent>
</Popover>
```

## Usage

```tsx
import { Button } from "@/components/ui/button";
import {
  Popover,
  PopoverContent,
  PopoverDescription,
  PopoverHeader,
  PopoverTitle,
  PopoverTrigger,
} from "@/components/ui/popover";
```

```tsx
<Popover>
  <PopoverTrigger render={<Button variant="outline" />}>Adjust times</PopoverTrigger>
  <PopoverContent>
    <PopoverHeader>
      <PopoverTitle>Prayer time adjustments</PopoverTitle>
      <PopoverDescription>Shift each time to match your local masjid.</PopoverDescription>
    </PopoverHeader>
  </PopoverContent>
</Popover>
```

The popover is positioned next to its trigger, flips when there is not enough space, and closes on
outside click or Escape.

## Examples

### Sides

Use `side` on `PopoverContent`. Prefer `inline-start` and `inline-end` over `left` and `right` so

## RTL

`inline-start` and `inline-end` resolve against the nearest direction, so the same code opens the
popover on the right in Arabic and on the left in English. `align="start"` is also logical.

The popover is rendered in a portal outside your RTL subtree, so it follows the nearest
`DirectionProvider`. Wrap RTL apps with `<DirectionProvider direction="rtl">` from the
`direction` item so the popover mirrors correctly.
