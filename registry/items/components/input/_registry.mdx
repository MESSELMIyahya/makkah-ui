## Anatomy

```tsx
<Input type="text" />
```

## Usage

```tsx
import { Input } from "@/components/ui/input";
```

```tsx
<Input type="email" placeholder="name@example.com" />
```

Pair every input with a `Label` (or `Field`) and use `type` and `inputMode` to bring up the right
keyboard on mobile, for example `type="number"` for zakat amounts.

## RTL

Text alignment and padding follow the document direction. Values that are always left-to-right,
such as email addresses or URLs, can keep `dir="ltr"` on the input itself while the rest of the
form stays right-to-left.
