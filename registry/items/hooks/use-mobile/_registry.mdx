## Usage

Call `useIsMobile` to switch between compact and full layouts. The hook subscribes to a
`matchMedia` query with `useSyncExternalStore`, so it updates when the viewport crosses the
breakpoint and returns `false` during server rendering.

```tsx
import { useIsMobile } from "@/hooks/use-mobile";

// Your own app components.
import { CompactPrayerTimes, WeeklyPrayerTimesTable } from "@/components/prayer-times";

export function PrayerTimes() {
  const isMobile = useIsMobile();

  return isMobile ? <CompactPrayerTimes /> : <WeeklyPrayerTimesTable />;
}
```

## API Reference

### useIsMobile

Takes no arguments. The breakpoint query is `(max-width: 63.999rem)`, matching the Tailwind `lg` breakpoint.
